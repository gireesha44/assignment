## 📐 Page Architecture

1. **Navigation Bar**
   - Brand logo mark with "NEXORA ACADEMY"
   - Desktop and animated mobile drawer navigation
   - Smooth scrolling anchors: Programmes, Learning Path, Projects, Experience, Outcomes, FAQs
   - Action CTAs: "Talk to Advisor" & "Explore Programmes"

2. **Hero Section (Split-Screen Editorial Layout)**
   - Badge: *"Built Around Practical Learning | Zero Passive Slide Watching"*
   - Headline: *"Don't Just Learn AI. Build What Comes Next."*
   - Interactive Live Workbench Simulation: allows switching between RAG retrieval, automation crawlers, and ML risk classifiers with simulated code execution and terminal telemetry.
   - Direct CTAs: "Explore Programmes" & "Talk to a Learning Advisor"

3. **Value Proposition (Editorial Asymmetrical Layout)**
   - Headline: *"Skills Are Better When You Build With Them."*
   - Differentiator 01: **Learn by Doing** (with direct comparison: Video Tutorials vs Nexora Method)
   - Differentiator 02: **Build Portfolio-Ready Projects** (with GitHub repository card mockup)
   - Differentiator 03: **Work With Modern AI Tools** (LangChain, ChromaDB, OpenAI/Anthropic APIs, Docker)
   - Differentiator 04: **Learn Through Guided Practice** (architecture deconstruction to deployment)

4. **Programme Discovery**
   - Headline: *"Find Your Next Learning Path."*
   - 6 Core Categories with category filter tabs, search bar, and difficulty filter:
     - A. AI & Generative AI
     - B. Machine Learning Foundations
     - C. Full Stack Web Development
     - D. Python & Automation
     - E. Data Analytics
     - F. Digital Productivity & AI Tools
   - Each card features: Title, Short description, Difficulty level, Duration (illustrative pace), Key skills chips, Capstone project outcome highlight, "Explore Programme" modal trigger, and "Quick Apply" action.
   - Comprehensive **Programme Detail Modal** with week-by-week syllabus milestones, tools mastered, prerequisites, and 1-click application prefill.

5. **Build-to-Learn Path**
   - Interactive 4-step horizontal journey & timeline stepper:
     - **STEP 01 — Discover:** Understand the fundamentals with architecture blueprints.
     - **STEP 02 — Experiment:** Work with AI tools and API playgrounds.
     - **STEP 03 — Build:** Develop modular, production-grade projects.
     - **STEP 04 — Showcase:** Deploy live applications and publish verified GitHub repos.

6. **Project Showcase**
   - Headline: *"Your Skills Should Have Something to Show."*
   - 5 Capstone Projects with interactive application mockups:
     1. **AI-Powered Document Assistant** (NexusDoc)
     2. **Intelligent Personal Finance Assistant** (FinPulse)
     3. **Automated Content Generation Tool** (OmniPublish)
     4. **Data Analytics Dashboard** (MetricVibe)
     5. **Full-Stack Marketplace** (SkillCraft)
   - Interactive **Architecture Blueprint Modal** with tech tags, benchmark metrics, and production highlights.

7. **Learning Experience**
   - Six structured pillars: Guided Lessons, Practical Assignments, Project-Based Learning, Learning Resources, Progress Tracking, and Mentorship/Advisor Support (transparently labelled as a programme option).
   - Simulated Nexora Student Portal with sprint checklist and code review feedback.

8. **Outcomes Section**
   - Headline: *"From Curious Beginner to Confident Builder."*
   - 6 Core Competencies: Problem Solving, AI Literacy, Programming, Product Thinking, Portfolio Development, Technical Communication.
   - Clear benchmark proof criteria and our academic transparency commitment.

9. **Registration & Lead Capture (Critical Feature)**
   - Headline: *"Your Next Chapter Starts Here."*
   - Tabbed Switch: **"Submit Full Application"** vs **"Request a Callback"**
   - Comprehensive validation: full name, email format regex, phone number format, educational status, programme of interest, experience level, preferred learning format, and privacy consent checkbox.
   - Zero external transmission (local demo state).
   - Celebration canvas confetti and rich Confirmation Screen summarizing the application, outlining next steps, and offering an instant downloadable curriculum brief.

10. **FAQ Section**
    - Expandable accordion components with category filters and real-time search.
    - Covers all required questions transparently.

11. **Final CTA**
    - Headline: *"Your Ideas Deserve More Than Just Tutorials."*
    - Dual conversion action buttons and trust validation badges.

12. **Footer**
    - Brand logo, tagline, track quick links, platform navigation, contact details, social placeholders, and legal policies.
