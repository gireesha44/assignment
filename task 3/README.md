# FRAMEFLOW AI
> **From One Idea to a Publish-Ready Story.**

FrameFlow AI is an AI-assisted content production studio designed for founders, educators, creators, and marketing teams. It allows founders to create professional Instagram and LinkedIn carousels independently without needing an in-house graphic designer or agency.

---

## 🚀 Key Features

### 1. Studio Overview Dashboard
- Headline: *"Turn Your Ideas Into Stories Worth Sharing."*
- Quick action launchers for high-converting social topics.
- Live pipeline status widget tracking drafts from ingestion to export.
- Filterable project drawer (All, Publish-Ready, Drafts).
- Realistic social thumbnail cards with slide counts and platform badges.

### 2. Multi-Step Content Creation Workspace
1. **Step 1 — Idea Input**:
   - Headline: *"What do you want to talk about today?"*
   - Raw idea textarea with prompt presets.
   - Platform selector: Instagram / LinkedIn / Both.
   - Audience: Students / Professionals / Founders / General.
   - Tone: Educational / Conversational / Professional / Bold.
   - Slide count slider (5–10 slides).
   - Content objective: Educational Value, Brand Authority, Lead Generation, Viral Growth, Community Engagement.
2. **Step 2 — AI Research & Narrative Structure**:
   - Topic summary, target demographic, content angle.
   - Key takeaways grounding the slides.
   - Suggested headlines and psychological hook formulas.
   - Research dossier with source placeholders and explicit AI transparency disclosures.
3. **Step 3 — Slide-by-Slide Content Outliner**:
   - Full copy breakdown: Slide headline, body text, supporting detail/pro-tip, visual suggestions, and slide types.
   - Complete inline editing, insertion, duplication, and reordering.
4. **Step 4 — Visual Design & Aesthetic System**:
   - 5 curated design themes:
     - **Modern Gradient** (Vibrant violet-blue mesh, glassmorphism)
     - **Bold Tech** (High-contrast cyan tech, monospace labels)
     - **Editorial Minimal** (Quiet luxury, crisp Scandinavian spacing)
     - **Professional Corporate** (Executive deep sapphire authority)
     - **Playful Education** (Warm amber/coral creator energy)
   - One-click Brand Kit token synchronization.
5. **Step 5 — 3-Panel Carousel Editor**:
   - **Left Rail**: Slide thumbnails with drag-and-drop reordering, duplication, deletion, and quick addition.
   - **Center Canvas**: Authentic LinkedIn document viewer simulator and Instagram feed simulator with navigation controls and page indicators.
   - **Right Inspector**: Real-time content editing, layout archetype switcher (Hero Hook, Tool Showcase, Split Card, CTA, Standard), accent color swatches, background overrides, and typography scaling.
6. **Step 6 — Multi-Format Export Studio**:
   - Actual **1080x1080 Multi-Page PDF** compilation for LinkedIn document posts.
   - High-resolution single and batch **PNG export** for Instagram.
   - Formatted social post caption generator with 1-click clipboard copy.
   - Browser print dialog alternative.

### 3. Visual Workflow & Production Architecture
- 8-stage interactive pipeline: Founder Idea → AI Topic Research → Content Structuring → Headline & Slide Copy → Visual Direction → Carousel Generation → Founder Review → Final Export.
- Detailed input, output, automation tips, and human-in-the-loop checks for each stage.
- Real-world production architecture blueprint detailing n8n webhooks, Gemini 1.5 Pro, and Perplexity grounding with unit cost breakdowns (~$0.0215 per deck).
- Standardized JSON schema specification.

### 4. Brand Kit
- Centralized brand assets: Name, handle, tagline, avatar presets, primary/secondary colors, and typography.
- Automatically brands new carousel generations.

## 🛠️ Tech Stack

- **React 18** (Modern functional components, hooks, Context API)
- **TypeScript** (Strict type definitions)
- **Vite** (Next-generation frontend tooling)
- **Tailwind CSS** (Tokenized theme design system)
- **Lucide React** (Clean, consistent iconography)
- **jsPDF & html-to-image** (Real client-side 1080x1080 vector PDF and high-res PNG export)
